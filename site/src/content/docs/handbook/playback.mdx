Play, pause, and seek through media, with player state that tracks what the media is doing.

## How it works

Three features own playback state:

- The <DocsLink slug="reference/feature-playback">playback feature</DocsLink> tracks `paused`, `ended`, `started`, and `waiting`, and provides the `play()`, `pause()`, and `togglePaused()` actions. `play()` returns the native promise from the media element.
- The <DocsLink slug="reference/feature-time">time feature</DocsLink> tracks `currentTime`, `duration`, and `seeking`, and provides `seek(time)`. The seek action clamps the target to the media duration, waits for metadata if it hasn't loaded yet, and resolves with the time the media actually landed on.
- The <DocsLink slug="reference/feature-playback-rate">playback rate feature</DocsLink> tracks `playbackRate` and the available `playbackRates`, and provides `setPlaybackRate(rate)`.

The components consume this state through selectors. <DocsLink slug="reference/play-button">PlayButton</DocsLink> renders play, pause, and replay states from `paused` and `ended`; <DocsLink slug="reference/time-slider">TimeSlider</DocsLink> maps `currentTime` and `duration` to a slider; <DocsLink slug="reference/time">Time</DocsLink> formats time values for display.

While a seek is in flight, the player holds the seek target as an optimistic `currentTime` so the time slider doesn't snap back to the old position before the media catches up.

## Availability and constraints

- `play()` can be blocked by the browser when it isn't triggered by a user gesture and autoplay conditions aren't met. The returned promise rejects with a `NotAllowedError`. See <DocsLink slug="handbook/autoplay">Autoplay</DocsLink>.
- `waiting` is `true` when the media is playing but doesn't have enough data. Use it for buffering UI rather than listening to media events. The <DocsLink slug="reference/buffering-indicator">BufferingIndicator</DocsLink> component does this for you.
- For live streams, `duration` reports the live edge (the end of the last seekable range) instead of `Infinity`, and it grows as the DVR window slides.
- Some media types can't change playback rate; `setPlaybackRate` is a no-op for media that doesn't support it.

## Common variations

### Skip buttons

<DocsLink slug="reference/seek-button">SeekButton</DocsLink> seeks relative to the current position with its `seconds` prop; negative values seek backward.

<FrameworkCase frameworks={["react"]}>

```tsx
import { SeekButton } from '@videojs/react';

function SkipButtons() {
  return (
    <>
      <SeekButton seconds={-10} render={(props) => <button {...props}>-10s</button>} />
      <SeekButton seconds={30} render={(props) => <button {...props}>+30s</button>} />
    </>
  );
}
```

</FrameworkCase>

### Imperative control

<FrameworkCase frameworks={["react"]}>

Call playback actions directly on the player store for custom UI or app logic. Within a provider, get the store from <DocsLink slug="reference/use-player">`Player.usePlayer`</DocsLink>:

```tsx
import { createPlayer } from '@videojs/react';
import { Video, videoFeatures } from '@videojs/react/video';

const Player = createPlayer({ features: videoFeatures });

function SkipIntroButton() {
  const store = Player.usePlayer();

  return (
    <button type="button" onClick={() => store.seek(90)}>
      Skip intro
    </button>
  );
}

export default function App() {
  return (
    <Player.Provider>
      <Player.Container>
        <Video src="https://stream.mux.com/BV3YZtogl89mg9VcNBhhnHm02Y34zI1nlMuMQfAbl3dM/highest.mp4" playsInline />
        <SkipIntroButton />
      </Player.Container>
    </Player.Provider>
  );
}
```

</FrameworkCase>
<FrameworkCase frameworks={["html"]}>

Call playback actions on the player store through the <DocsLink slug="reference/player-controller">player controller</DocsLink>, or use the media element directly:

```html
<video-player>
  <media-container>
    <video src="https://stream.mux.com/BV3YZtogl89mg9VcNBhhnHm02Y34zI1nlMuMQfAbl3dM/highest.mp4" playsinline></video>
  </media-container>
</video-player>
<button type="button" id="skip-intro">Skip intro</button>
<script type="module">
  import '@videojs/html/video/player';

  document.querySelector('#skip-intro').addEventListener('click', () => {
    document.querySelector('video').currentTime = 90;
  });
</script>
```

</FrameworkCase>

## Troubleshooting

### play() rejects with NotAllowedError

The browser requires a user gesture to start playback. Trigger `play()` from a click handler, or use muted autoplay. See <DocsLink slug="handbook/autoplay">Autoplay</DocsLink>.

### The duration shows 0:00

The media metadata hasn't loaded. Check that the source loads, and that `preload` isn't set to `none` when you need the duration before playback starts.

### Seeking is slow or jumps

Seeking to unbuffered positions requires the browser to fetch new data; progressive MP4 files need byte-range support on the server for efficient seeking. Streaming formats (HLS, DASH) seek segment by segment. See <DocsLink slug="handbook/sources-and-loading">Sources and Loading</DocsLink>.
